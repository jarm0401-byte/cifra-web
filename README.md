# CIFRA — Estudio digital

Sitio web del estudio. Proyecto 001.

**Stack:** HTML/CSS/JS estático, sin dependencias ni build step. Un solo archivo: `index.html`.

**Sistema de diseño:** basado en la especificación editorial OFF+BRAND (refero.design) —
parchment `#e5e4e0`, ink `#1d1d1d`, tipografía monumental (Inter), radios 0px en tarjetas /
10px en interactivos, cero sombras, un solo acento cromático (esfera con gradiente).

**Ver en local:** abrir `index.html` en el navegador. Modo de captura sin animaciones:
`index.html?static`.

**Despliegue:** Vercel, importado desde este repositorio. Cada push a `main` despliega
automáticamente.
